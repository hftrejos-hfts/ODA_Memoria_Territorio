# ODA · Memoria, territorio y guaquería en Colombia

Sitio estático listo para publicar con **GitHub Pages**. Su diseño utiliza el marco ilustrado suministrado por el docente.

## Publicación en GitHub Pages

1. Crea un repositorio público en GitHub (por ejemplo `oda-memoria-territorio`).
2. Sube `index.html` y la carpeta `assets/` a la **raíz** del repositorio. Mantén la estructura de carpetas.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch** y la rama `main`, carpeta `/(root)`. Guarda.
5. Cuando GitHub publique la página, abre el enlace que aparecerá en Pages. Generalmente adopta la forma `https://USUARIO.github.io/oda-memoria-territorio/`.
6. En Moodle, añade un recurso **URL** y pega esa dirección. Selecciona abrir en ventana nueva si lo prefieres.

## Características

- No necesita instalar paquetes ni compilar.
- Navegación entre 11 pantallas temáticas.
- Caso de estudio *hipotético* y actividad de decisiones con retroalimentación.
- Autoevaluación local de 4 preguntas, sin calificación registrada en Moodle.
- Referencias enlazadas a fuentes institucionales.
- Adaptable a dispositivos móviles.

## Vista previa local

Abre `index.html` en un navegador o ejecuta desde esta carpeta `python3 -m http.server 8000` y visita `http://localhost:8000`.

## Consideraciones

- La calificación de la autoevaluación **no** se envía a Moodle. Para seguimiento o notas automáticas, se necesita una integración adicional (por ejemplo SCORM/H5P/LTI).
- Si el repositorio es público, todo el contenido y las ilustraciones de la carpeta serán públicamente accesibles. Verifica los derechos para su publicación.
- Los hipervínculos a ICANH y UNESCO requieren conexión a internet.
